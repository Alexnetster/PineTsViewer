📊 Donchian Channels Reference

Pine Script: donchian.pine → Pure LWC TypeScript Implementation (Channel Fill)

📋 구현 사양

  • Bounds: Highest High / Lowest Low (Period 20)
  • Rendering: 3 Line Series + Orange Channel Fill
  • Logic: Standard Donchian (Price Channel)

🔍 검증 방법

  • 상단 밴드가 N기간 최고가, 하단 밴드가 최저가를 따라가는지 확인
  • 주황색 영역 채우기(Fill)가 정상 표시되는지 확인
  • JSON.stringify(window.referenceData)로 계산 값 검증

⚙️ 파라메터 상세

  • Length: [범위: 1+] 기간 (기본값: 20). 해당 기간의 최고가/최저가 사용.
  • 장점: 가격의 절대적인 고점과 저점을 시각화. 박스권 돌파 매매에 유용.
  • 사용법: 상단 밴드 돌파 시 신고가(매수), 하단 밴드 이탈 시 신저가(매도).
  • 추천 시간대: 4시간봉(H4), 일봉(D1), 주봉(W1). 터틀 트레이딩 전략의 핵심.
  • 비추천: 횡보장, 휩소가 많은 짧은 분봉.
  • 시너지 지표: ATR(손절폭 설정), Moving Average.
