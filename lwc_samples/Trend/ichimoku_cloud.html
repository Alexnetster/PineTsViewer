📊 Ichimoku Cloud Reference

Pine Script: ichimoku.pine → Pure LWC TypeScript Implementation with Cloud Fill

📋 구현 사양

  • Tenkan-sen (전환선): 9기간 (Blue)
  • Kijun-sen (기준선): 26기간 (Red)
  • Chikou Span (후행스팬): 종가를 26기간 과거로 이동 (Green)
  • Senkou Span A/B (선행스팬): 26기간 미래로 이동
  • Kumo (구름대): Span A와 Span B 사이 영역 채우기

🔍 검증 방법

  • 브라우저 콘솔에서 JSON.stringify(window.referenceData) 실행
  • PineTS 컴파일 결과와 변환된 일목균형표 값(전환선, 기준선, 스팬 A/B) 비교
  • 구름대(fill)가 선행스팬 A/B 사이에 정확히 그려지는지 시각적 확인

⚙️ 파라메터 상세

  • Conversion Line Periods: [범위: 1+] 전환선 기간 (기본값: 9). 단기 추세.
  • Base Line Periods: [범위: 1+] 기준선 기간 (기본값: 26). 중기 추세.
  • Lagging Span 2 Periods: [범위: 1+] 선행스팬2 계산 기간 (기본값: 52). 장기 추세.
  • Displacement: [범위: 1+] 선행/후행 스팬 이동 값 (기본값: 26). 예측 및 확인용.
  • 장점: 지지/저항, 추세 방향, 모멘텀을 한눈에 파악.
  • 사용법: 구름대 위는 상승 추세, 아래는 하락 추세. 전환선이 기준선을 상향 돌파하면 매수 신호.
  • 추천 시간대: 4시간봉(H4), 일봉(D1). (일본식 지표는 일봉 기준 최적화 경향)
  • 비추천: 1분봉, 5분봉. (구름대가 얇아 신뢰도 하락)
  • 시너지 지표: RSI, Price Action(캔들 패턴).
