📊 Moving Averages Quote

Pine Script: ma_quote.pine → Pure LWC TypeScript Implementation

📋 구현 사양

  • SMA(20): 단순 이동평균, 빨간색 (#FF5252)
  • EMA(50): 지수 이동평균, 주황색 (#FFB74D)
  • WMA(100): 가중 이동평균, 파란색 (#2196F3)
  • 다중 라인: 여러 개의 LineSeries를 동시에 렌더링

🔍 검증 방법

  • 브라우저 콘솔에서 JSON.stringify(window.referenceData) 실행
  • PineTS 컴파일 결과와 계산된 MA (SMA, EMA, WMA) 값 비교
  • 시각적으로 다양한 이동평균선이 겹쳐서 표시되는지 확인

⚙️ 파라메터 상세

  • Period: [범위: 1~200+] 이동평균 계산 기간 (기본값: SMA 20, EMA 50, WMA 100).
  • Type: [SMA, EMA, WMA, RMA] 이동평균 종류. SMA는 단순, EMA는 최근 데이터 가중.
  • 장점: 추세의 방향성을 가장 직관적으로 파악. 노이즈 스무딩.
  • 사용법: 단기 이평선이 장기 이평선을 상향 돌파(골든크로스) 시 매수, 하향 돌파(데드크로스) 시 매도.
  • 추천 시간대: 모든 시간대. (단, 목적에 맞게 주기 설정 필요. 스캘핑은 5/20, 스윙은 50/200)
  • 비추천: 횡보장에서의 크로스 오버 매매. (Since Whipsaw)
  • 시너지 지표: 거의 모든 지표의 기준(Base)으로 사용됨.
