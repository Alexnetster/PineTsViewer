📊 Ease of Movement Reference

Pine Script: eom.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: SMA(Distance Moved / Box Ratio, 14)
  • Visualization: Line Series (Orange)
  • Sub-Chart Layout: 메인 가격 차트와 별도의 EOM 차트 분리

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • 값이 0을 중심으로 움직이는지 확인

⚙️ 파라메터 상세

  • Length: [범위: 1+] 기간 (기본값: 14).
  • Divisor: [범위: 1000~] 값의 스케일 조정을 위한 제수 (기본값: 10000).
  • 장점: 가격이 얼마나 '쉽게' 움직이는지 파악. 거래량이 적은데 가격이 오르면 주의.
  • 사용법: 0선 상향 돌파는 상승 룸이 열림, 하향 돌파는 하락 룸이 열림.
  • 추천 시간대: 일봉.
  • 비추천: 분봉(값이 튐).
  • 시너지 지표: Volume.
