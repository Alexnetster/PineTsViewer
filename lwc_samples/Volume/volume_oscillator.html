📊 Volume Oscillator Reference

Pine Script: volume_oscillator.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: (FastSMA(Vol) - SlowSMA(Vol)) / SlowSMA(Vol) * 100
  • Visualization: Histogram Series with Color Logic
  • Sub-Chart Layout: 메인 가격 차트와 별도의 Vol Osc 차트 분리

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • Positive/Negative 값에 따라 히스토그램 색상이 변하는지 확인

⚙️ 파라메터 상세

  • Short Length: [범위: 1+] 단기 거래량 이평 (기본값: 5).
  • Long Length: [범위: 1+] 장기 거래량 이평 (기본값: 10).
  • 장점: 거래량의 증감을 파악하여 추세의 힘 측정.
  • 사용법: 0선 위는 단기 거래량 증가(추세 활발), 아래는 감소(소강 상태).
  • 추천 시간대: 브레이크아웃(돌파) 매매 시 모든 시간대 활용.
  • 비추천: -
  • 시너지 지표: Bollinger Bands(밴드 돌파 시 거래량 폭발 확인).
