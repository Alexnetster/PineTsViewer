📊 Accumulation/Distribution Reference

Pine Script: ad.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: Cumulative Sum of Money Flow Volume
  • Visualization: Line Series (Blue)
  • Sub-Chart Layout: 메인 가격 차트와 별도의 A/D 차트 분리

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • A/D 값이 누적되어 변하는지 확인

⚙️ 파라메터 상세

  • 기준: 시가, 고가, 저가, 종가, 거래량을 모두 활용.
  • 장점: OBV보다 더 정교한 매집/분산 지표.
  • 사용법: 가격과 A/D 라인의 다이버전스를 확인하여 추세의 건전성 판단.
  • 추천 시간대: 일봉 이상.
  • 비추천: 단타.
  • 시너지 지표: Price Action.
