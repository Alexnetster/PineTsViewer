📊 Chaikin Money Flow Reference

Pine Script: cmf.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: Sum(AD) / Sum(Volume) over period 20
  • Visualization: Dual Area Series (Green for >0, Red for < 0)
  • Sub-Chart Layout: 메인 가격 차트와 별도의 CMF 차트 분리

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • CMF 값이 0을 기준으로 색상이 Green/Red로 나뉘는지 확인

⚙️ 파라메터 상세

  • Length: [범위: 1+] 기간 (기본값: 20).
  • 장점: 일정 기간 동안의 매집/분산 압력을 측정.
  • 사용법: 0선 위에 머무르면 매수 압력 우위(강세), 아래면 매도 압력 우위(약세).
  • 추천 시간대: 일봉, 주봉. 중장기 자금 흐름 파악.
  • 비추천: 스캘핑.
  • 시너지 지표: Moving Average.
