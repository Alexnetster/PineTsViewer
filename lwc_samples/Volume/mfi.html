📊 Money Flow Index Reference

Pine Script: mfi.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: RSI applied to Volume-Weighted Price (MFI)
  • Sub-Chart Layout: 메인 가격 차트와 별도의 MFI 차트 분리
  • Levels: 20 (과매수) / 80 (과매도) 라인 표시
  • Synchronization: 두 차트의 TimeScale(줌/팬) 동기화

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • MFI 값이 0~100 범위 내에서 움직이는지 확인

⚙️ 파라메터 상세

  • Length: [범위: 1+] 기간 (기본값: 14).
  • 장점: '거래량이 실린 RSI'. 가격 움직임의 신뢰도 판단.
  • 사용법: 80 이상 과매수, 20 이하 과매도. 다이버전스 발생 시 추세 반전 신호.
  • 추천 시간대: 1시간봉 이상. RSI 보다 선행하는 경향.
  • 비추천: 거래량 없는 차트.
  • 시너지 지표: RSI(비교 분석).
