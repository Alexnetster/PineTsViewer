📋 구현 사양

  • 핵심 로직: 최근 캔들 중 의미 있는 고점/저점(Pivot)을 자동으로 찾습니다.
  • 시각화: 상승 주문 블록(매수세)은 초록색 박스, 하락 주문 블록(매도세)은 빨간색 박스로 그립니다.
  • 박스 확장: 각 박스는 해당 가격대의 영향력이 지속됨을 보여주기 위해 차트 오른쪽 끝까지 길게 그려집니다.

🔍 검증 방법

  • 박스 생성: 차트의 뾰족한 고점이나 저점 위치에 정확히 박스가 생기는지 확인하세요.
  • 고정 여부: 차트를 좌우로 스크롤했을 때 박스가 엉뚱한 곳으로 이동하지 않고 가격대에 잘 고정되어 있어야 합니다.
  • 줌 테스트: 차트를 확대/축소해도 박스 높이가 캔들 크기에 맞춰 올바르게 유지되는지 확인하세요.

⚙️ 파라메터 상세

  • Period: [기본: 5] 스윙 하이/로우를 식별하는 좌우 캔들 수.
  • 특징: 스마트 머니(기관)가 가격을 급격하게 움직이기 전에 남긴 마지막 반대 방향 캔들(매집/매도 흔적).
  • 장점: 막연한 지지/저항선보다 신뢰도가 높으며, 정확한 타점(손익비 좋음)을 제공.
  • 사용법: 가격이 Order Block 박스에 다시 도달(Retest)했을 때 반등을 예상하고 진입 (Limit Order).
  • 추천 시간대: 모든 시간대(Fractal). 하지만 1시간봉, 4시간봉 이상의 OB가 강력함.
  • 비추천: 뉴스 발표 직전(OB 무시하고 뚫릴 수 있음).
  • 시너지 지표: FVG(Fair Value Gap) - FVG를 채우러 가면서 OB에 도달할 때 가장 강력.
