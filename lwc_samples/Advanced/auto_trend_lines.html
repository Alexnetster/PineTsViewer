📊 Auto Trend Lines Reference

Pine Script: auto_trend_lines.pine → Pure LWC TypeScript Implementation (Calculated LineSeries)

📋 구현 사양

  • Calculation: Pivot Detection(10/10) + Min Distance Check (20 bars)
  • Logic: 최근 Pivot Point 중 유의미한 거리를 가진 두 점을 연결
  • Visualization: Line Series (Red=Resistance, Green=Support)

🔍 검증 방법

  • 고점끼리, 저점끼리 연결된 직선이 그려지는지 확인
  • 직선이 너무 짧거나 급격하지 않고, 전반적인 추세를 반영하는지 확인

⚙️ 파라메터 상세

  • 사용법: 추세선 리테스트 시 진입 기회 포착. 추세선 붕괴 시 추세 전환 신호.
  • 추천 시간대: 4시간봉, 일봉.
