📊 Pivot Points Reference

Pine Script: pivot.pine → Pure LWC TypeScript Implementation (Step Lines)

📋 구현 사양

  • Logic: Standard Pivot (Prev Day H/L/C → P, R1, S1)
  • Visual: Step-like Lines (changes daily)
  • Constraint: Using LineSeries to represent levels

🔍 검증 방법

  • 하루가 지날 때 피벗 라인들이 갱신되어 계단 형태로 나타나는지 확인
  • R1 > P > S1 관계가 유지되는지 확인
  • JSON.stringify(window.referenceData)로 계산 값 검증

⚙️ 파라메터 상세

  • Type: [Traditional, Fibonacci, Woodie, DM...] 계산 방식 선택.
  • Timeframe: [Auto, Daily, Weekly, Monthly] 기준 시간대.
  • 장점: 당일 혹은 주간의 주요 가격 변곡점 예상. 데이트레이딩 필수.
  • 사용법: Pivot 위는 강세, 아래는 약세. R1, S1 등 주요 레벨에서의 반작용 활용.
  • 추천 시간대: 데이트레이딩(5분/15분 본차트 + Daily Pivot).
