📊 ICT Fair Value Gaps (FVG) Reference

Pine Script: ict_fvg.pine → Custom LWC Box Primitive (Mitigation + ATR Filter)

📋 구현 사양

  • Pattern: 3-Candle Structure with Gap
  • Bullish FVG: Low(C3) > High(C1) (Green Zone)
  • Bearish FVG: High(C3) < Low(C1) (Red Zone)
  • Mitigation: 가격이 갭을 메우면 자동 제거
  • ATR Filter: Gap Size >= 0.5 * ATR(14)

🔍 필터링 로직

  • Mitigation Check: Bullish FVG는 Close < Top 시, Bearish FVG는 Close> Bottom 시 제거
  • Minimum Gap Size: ATR 기반 필터로 노이즈 제거
  • Max Boxes: 최근 10개 Active FVG만 표시

⚙️ 파라메터 상세

  • Threshold: [범위: 0.1+] 갭의 최소 크기 (ATR 배수 등).
  • 장점: 급격한 가격 이동으로 인해 체결되지 않은 주문이 남은 구간(Fair Value Gap) 식별.
  • 사용법: 가격은 FVG를 메우러 돌아오는 경향이 있음. FVG 구간에서 지지/저항 확인.
  • 추천 시간대: 1시간봉, 15분봉. ICT 매매기법의 핵심.
  • 비추천: 거래량 없는 시간대.
  • 시너지 지표: Liquidity Sweep, Order Block.

🔍 검증 방법

  • 브라우저 콘솔에서 JSON.stringify(window.referenceData) 확인.
  • 차트 렌더링 상태 시각적 점검.
