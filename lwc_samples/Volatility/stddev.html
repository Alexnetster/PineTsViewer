📊 Standard Deviation Reference

Pine Script: stddev.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: SQRT(Mean((Close - SMA)^2))
  • Visualization: Line Series (Red)
  • Sub-Chart Layout: 메인 가격 차트와 별도의 StdDev 차트 분리

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • 가격 변동성이 클 때 값이 올라가는지 확인

⚙️ 파라메터 상세

  • Length: [범위: 1+] 기간 (기본값: 20).
  • 장점: 통계적인 변동성 측정. 볼린저 밴드의 기초.
  • 사용법: 값이 매우 낮으면 곧 변동성 폭발 가능성. 높으면 추세 반전 주의.
  • 추천 시간대: 전 시간대.
  • 비추천: -
  • 시너지 지표: Bollinger Bands.
