📊 ATR Reference

Pine Script: atr.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Logic: Average True Range (Wilder's SMA/RMA)
  • Visual: Volatility Line in Sub-Chart
  • Verification: 캔들 크기가 커질 때 값 상승 확인

🔍 검증 방법

  • 변동성이 커지는 구간(캔들 길이 증가)에서 ATR 값이 상승하는지 확인
  • RMA 계산의 초기화 및 진행이 올바른지 확인
  • JSON.stringify(window.referenceData)로 계산 값 검증

⚙️ 파라메터 상세

  • Length: [범위: 1+] 기간 (기본값: 14).
  • 장점: 절대적인 변동성 크기 측정. 손절매(Stop Loss) 폭 설정에 필수.
  • 사용법: ATR 값이 높으면 변동성 확대(리스크 증가), 낮으면 축소. 추세 방향은 알려주지 않음.
  • 추천 시간대: 모든 시간대(익절/손절 계산용). 특히 4시간/일봉 ATR은 데일리 레인지 예측에 유용.
  • 비추천: 진입 시그널용으로는 부적합(방향성 없음).
  • 시너지 지표: Keltner Channels, SuperTrend(ATR 기반).
