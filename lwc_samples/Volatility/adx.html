📊 ADX/DMI Reference

Pine Script: adx.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Logic: DMI(DI+, DI-) Calculation & ADX (Average Directional Index)
  • Visual: 3 Lines (Pink ADX, Green +DI, Red -DI)
  • Constraint: Using Wilder's RMA for smoothing

🔍 검증 방법

  • ADX가 25 이상일 때 추세가 강한지 확인
  • DI+와 DI-의 교차가 추세 방향과 일치하는지 확인
  • JSON.stringify(window.referenceData)로 계산 값 검증

⚙️ 파라메터 상세

  • ADX Smoothing: [범위: 1+] ADX 스무딩 기간 (기본값: 14).
  • DI Length: [범위: 1+] DI 계산 기간 (기본값: 14).
  • 장점: 추세의 '강도'를 측정하는 최고의 지표.
  • 사용법: ADX가 25 이상이면 강한 추세장. DI+가 DI-보다 위에 있으면 상승 추세.
  • 추천 시간대: 4시간봉, 일봉. 진짜 추세를 거르는 필터로 사용.
  • 비추천: 횡보장(ADX 20 이하일 때는 모든 추세 지표 무시).
  • 시너지 지표: SAR(ADX 강세일 때만 SAR 신호 따르기).
