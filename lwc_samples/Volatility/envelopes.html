📊 Envelopes Reference

Pine Script: envelopes.pine → Pure LWC TypeScript Implementation (Overlay)

📋 구현 사양

  • Calculation: SMA(20) ± 5%
  • Visualization: Upper/Lower Line Series
  • Main Chart Overlay: 캔들스틱 차트 위에 오버레이

🔍 검증 방법

  • 중앙선(오렌지)과 상하단선(파랑)이 평행하게 움직이는지 확인
  • 가격이 밴드 내/외부로 움직이는지 확인

⚙️ 파라메터 상세

  • Length: [범위: 1+] 기준 MA 기간 (기본값: 20).
  • Percent: [범위: 0.1~10] 상하단 편차 퍼센트 (기본값: 10).
  • 장점: 가격의 정상 범위를 시각화.
  • 사용법: 밴드 도달 시 과매수/과매도로 판단하고 역추세 매매나, 돌파 시 추세 추종에 활용.
  • 추천 시간대: 스캘핑(작은 % 설정), 스윙(큰 % 설정).
  • 비추천: -
  • 시너지 지표: RSI(과매수/과매도 확인).
