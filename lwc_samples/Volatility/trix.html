📊 Trix Reference

Pine Script: trix.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: ROC of Triple EMA (EMA3)
  • Visualization: Line Series (Purple)
  • Sub-Chart Layout: 메인 가격 차트와 별도의 Trix 차트 분리

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • 값이 0을 기준으로 움직이는지 확인

⚙️ 파라메터 상세

  • Length: [범위: 1+] 기간 (기본값: 15).
  • 장점: 3중 평활로 노이즈를 극도로 제거하여 주요 추세만 남김.
  • 사용법: 0선 교차 및 시그널 선 교차를 통해 중장기 추세 매매 활용.
  • 추천 시간대: 일봉, 주봉. 매크로 트렌드 확인.
  • 비추천: 단타(반응 늦음).
  • 시너지 지표: MACD(비교 검증).
