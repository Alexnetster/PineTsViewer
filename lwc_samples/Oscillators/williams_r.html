📊 Williams %R Reference

Pine Script: williams.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: (Highest High - Close) / (HH - LL) * -100
  • Sub-Chart Layout: 메인 가격 차트와 별도의 %R 차트 분리
  • Levels: -20 (과매수) / -80 (과매도) 라인 표시
  • Synchronization: 두 차트의 TimeScale(줌/팬) 동기화

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • 값이 0 ~ -100 사이에서 움직이는지 확인

⚙️ 파라메터 상세

  • Length: [범위: 1+] 계산 기간 (기본값: 14).
  • 장점: 스토캐스틱보다 빠른 반응 속도. 초단기 매매에 유용.
  • 사용법: -20 이상은 과매수(매도 고려), -80 이하는 과매도(매수 고려).
  • 추천 시간대: 1분봉, 5분봉 스캘핑.
  • 비추천: 장기 투자.
  • 시너지 지표: Volume Indicator.
