📊 MACD Reference

Pine Script: macd.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • MACD Line: EMA(12) - EMA(26) (Blue)
  • Signal Line: EMA(9) of MACD (Orange)
  • Histogram: MACD - Signal
  • Colors: 성장/감소에 따른 4가지 색상 (Green/LightGreen/Red/LightRed)
  • Sub-Chart: 독립된 축을 가진 하단 차트

🔍 검증 방법

  • 히스토그램 색상이 전일 대비 증감에 따라 변하는지 확인
  • MACD > Signal 일 때 히스토그램이 양수(Green)인지 확인
  • JSON.stringify(window.referenceData)로 계산 값 검증

⚙️ 파라메터 상세

  • Fast Length: [범위: 1+] 단기 EMA 기간 (기본값: 12).
  • Slow Length: [범위: 1+] 장기 EMA 기간 (기본값: 26).
  • Signal Smoothing: [범위: 1+] MACD선의 스무딩 기간 (기본값: 9).
  • 장점: 추세와 모멘텀을 동시에 파악 가능. 골든/데드 크로스 신호.
  • 사용법: 히스토그램이 양수로 전환되거나 MACD선이 시그널선을 상향 돌파 시 매수.
  • 추천 시간대: 4시간봉(H4), 일봉(D1). 큰 추세 변화 포착에 탁월.
  • 비추천: 1분봉(신호가 너무 늦음). 후행성이 강함.
  • 시너지 지표: Stochastic(MACD가 방향 잡으면 스토캐스틱으로 눌림목 진입).
