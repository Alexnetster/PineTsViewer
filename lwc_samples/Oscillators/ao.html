📊 Awesome Oscillator Reference

Pine Script: ao.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: SMA(Median Price, 5) - SMA(Median Price, 34)
  • Visualization: Histogram Series
  • Color Logic: Rising (Green) / Falling (Red)
  • Sub-Chart Layout: 메인 가격 차트와 별도의 AO 차트 분리

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • 히스토그램 색상이 상승/하락에 따라 변하는지 확인

⚙️ 파라메터 상세

  • Fast Length: [범위: 1+] 단기 SMA (기본값: 5).
  • Slow Length: [범위: 1+] 장기 SMA (기본값: 34).
  • 장점: 시장의 모멘텀 변화를 히스토그램 색상으로 직관적 파악.
  • 사용법: 0선 상향 돌파는 매수, 하향 돌파는 매도 신호. Saucer 패턴 활용.
  • 추천 시간대: 파동 카운팅(엘리어트 파동) 보조용으로 전 시간대 활용.
  • 비추천: -
  • 시너지 지표: Alligator, Fractalls (빌 윌리엄스 조합).
