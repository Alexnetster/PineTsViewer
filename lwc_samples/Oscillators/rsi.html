📊 RSI Reference

Pine Script: rsi.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Wilder's Smoothing: 표준 RSI 계산 로직 (기본 14)
  • Sub-Chart Layout: 메인 가격 차트와 별도의 RSI 차트 분리
  • Levels: 70 (과매수) / 30 (과매도) 라인 표시
  • Synchronization: 두 차트의 TimeScale(줌/팬) 동기화

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • RSI 값이 0~100 범위 내에서 움직이는지 확인
  • JSON.stringify(window.referenceData)로 계산 값 검증

⚙️ 파라메터 상세

  • Period: [범위: 1~100] RSI 계산 기간 (기본값: 14). 짧을수록 민감.
  • 장점: 과매수(70 이상)와 과매도(30 이하) 구간 식별이 용이. 다이버전스 분석 가능.
  • 사용법: 30 상향 돌파 시 매수, 70 하향 이탈 시 매도. 주가와 지표의 다이버전스 주시.
  • 추천 시간대: 15분봉 이상. 다이버전스는 1시간봉/4시간봉에서 신뢰도 높음.
  • 비추천: 1분봉(노이즈 과다). 강력한 원웨이 상승/하락장(지표가 계속 과매수권에 머뭄 - 숏 치다 사망).
  • 시너지 지표: Bollinger Bands(RSI 다이버전스 + 하단 밴드 지지 = 강력한 매수 신호).
