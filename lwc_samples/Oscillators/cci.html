📊 CCI Reference

Pine Script: cci.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • Calculation: (Typical Price - SMA) / (0.015 * Mean Deviation)
  • Sub-Chart Layout: 메인 가격 차트와 별도의 CCI 차트 분리
  • Levels: +100 / -100 라인 표시
  • Synchronization: 두 차트의 TimeScale(줌/팬) 동기화

🔍 검증 방법

  • 스크롤/줌 시 상하단 차트가 같이 움직이는지 확인
  • CCI 값이 +100 과 -100 을 오가는지 확인

⚙️ 파라메터 상세

  • Length: [범위: 1+] 계산 기간 (기본값: 20).
  • 장점: 현재 가격이 이동평균과 얼마나 떨어져 있는지 측정. 주기적인 패턴 파악.
  • 사용법: +100 상향 돌파 시 강세, -100 하향 이탈 시 약세. 0선 교차 매매 활용.
  • 추천 시간대: 선물/크립토 단타(5분/15분). 변동성 돌파 감지에 유리.
  • 비추천: -
  • 시너지 지표: Parabolic SAR.
