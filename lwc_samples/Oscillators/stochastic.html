📊 Stochastic Reference

Pine Script: stochastic.pine → Pure LWC TypeScript Implementation (Dual Chart Layout)

📋 구현 사양

  • %K Line: (Close - Low) / (High - Low) (Blue)
  • %D Line: SMA of %K (Orange)
  • Levels: 80 (Overbought) / 20 (Oversold)
  • Inputs: K=14, D=3, Smooth=3
  • Sub-Chart: 독립된 축을 가진 하단 차트

🔍 검증 방법

  • 가격 고점/저점에 따라 스토캐스틱이 0~100 사이를 움직이는지 확인
  • %K와 %D의 교차 시점 확인
  • JSON.stringify(window.referenceData)로 계산 값 검증

⚙️ 파라메터 상세

  • K Period: [범위: 1+] %K 계산 기간 (기본값: 14).
  • D Period: [범위: 1+] %D(시그널) 스무딩 기간 (기본값: 3).
  • Smooth: [범위: 1+] %K의 스무딩 기간 (기본값: 3).
  • 장점: 횡보장에서 매매 타이밍 포착에 유리.
  • 사용법: 20 이하에서 %K가 %D를 상향 돌파 시 매수, 80 이상에서 하향 이탈 시 매도.
  • 추천 시간대: 박스권(횡보) 장세의 1분봉~1시간봉. 스캘핑에 유리.
  • 비추천: 강력한 추세장(계속 과매수/과매도에 머뭄).
  • 시너지 지표: MACD(추세 확인 후 진입 타이밍은 스토캐스틱으로).
